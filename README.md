# 과제 11: 삽입 정렬과 쉘 정렬 성능 비교 분석

## 1. 데이터 크기 증가에 따른 비교 횟수 변화
데이터 크기 $n$이 1,000부터 20,000까지 2배씩 증가함에 따라 각 정렬 알고리즘의 비교 횟수가 증가하는 양상은 다음과 같습니다.
- **삽입 정렬(Insertion Sort)**은 데이터 크기가 2배 증가할 때 비교 횟수가 약 4배(제곱 비례)로 급격히 증가합니다. 이는 무작위 데이터에서 평균 시간 복잡도가 $O(n^2)$이기 때문입니다.
- **쉘 정렬(Shell Sort)**은 데이터 크기가 증가하더라도 삽입 정렬에 비해 비교 횟수 증가 폭이 훨씬 완만합니다. 멀리 떨어진 요소들을 미리 정렬하여 전체적인 이동 및 비교 부담을 사전에 줄여주기 때문입니다.

## 2. 삽입 정렬과 쉘 정렬의 성능 차이
삽입 정렬은 이미 거의 정렬된 데이터에 대해서는 매우 효율적이지만, 무작위 데이터에서는 한 번에 한 칸씩만 인접한 원소와 비교하며 이동하므로 대규모 데이터에서 연산 횟수가 폭발적으로 증가합니다.
반면 쉘 정렬은 삽입 정렬의 이러한 단점을 보완하기 위해 고안된 알고리즘입니다. 큰 간격을 두고 요소를 먼저 정렬($h$-sorting)한 후 간격을 점차 줄여나가며, 최종적으로 간격이 1이 되었을 때는 데이터가 이미 거의 정렬된 상태가 되므로 전체적인 비교 횟수가 획기적으로 줄어듭니다.

## 3. 쉘 정렬의 기본 간격과 Knuth 수열의 성능 차이
- **기본 간격 수열(Shell's Original Sequence)**은 매 단계마다 간격을 절반으로 줄이는 방식($n/2, n/4, \dots, 1$)을 사용합니다.
- **Knuth 수열**은 $h(1) = 1$, $h(k+1) = 3h(k) + 1$ 점화식을 기반으로 생성된 수열($1, 4, 13, 40, 121, \dots$)을 사용합니다.
실험 결과, Knuth 수열을 적용한 쉘 정렬이 기본 간격 방식에 비해 대부분의 데이터 크기에서 더 적은 비교 횟수를 기록하며 우수한 성능을 보여줍니다.

## 4. 간격 수열이 쉘 정렬의 성능에 영향을 미치는 이유
쉘 정렬의 성능은 간격 수열의 선택에 매우 민감하게 좌우됩니다.
- 기본 간격 방식은 간격들이 서로 배수 관계(2의 거듭제곱)를 가집니다. 이 경우 특정 간격 단계에서 홀수 번째 위치의 요소들과 짝수 번째 위치의 요소들이 서로 독립적으로 다뤄져, 이전 단계에서 수행한 정렬 효과가 다음 간격 단계에서 제대로 활용되지 못하고 쉽게 깨지는 현상이 발생할 수 있습니다.
- 반면 Knuth 수열은 간격 간의 공약수가 적거나 서로소에 가까운 특성을 유지하므로, 이전 단계에서 정렬된 부분 집합의 정렬 상태가 다음 단계에서도 효과적으로 유지됩니다. 따라서 불필요한 중복 비교가 줄어들고 데이터가 빠르게 최종 정렬 상태로 수렴하게 되어 더 뛰어난 성능을 발휘합니다.
